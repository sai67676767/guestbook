# Гостевая книга на Docker Compose

## Описание проекта

Гостевая книга, собранная в docker compose, работает на трёх контейнерах: nginx, backend (Python), база данных (PostgreSQL). Пользователи могут оставлять сообщения и удалять их.

## Возможности

- добавление сообщения (имя + текст)
- просмотр всех сообщений (сначала новые)
- удаление сообщения

## Стек технологий

- Backend: Python + FastAPI
- База данных: PostgreSQL
- Frontend: HTML + CSS + JavaScript
- Веб-сервер: Nginx
- Контейнеризация: Docker + Docker Compose

## Структура репозитория

Проект состоит из трёх папок: backend, frontend, nginx

**backend** — тут лежит код на Python. Внутри файлы:

- main.py с логикой API
- database.py с подключением к базе данных
- models.py с описанием таблицы
- schemas.py со схемами валидации
- crud.py с функциями работы с базой
- requirements.txt со списком библиотек
- Dockerfile (инструкция контейнера)

**frontend** — тут файл index.html. Это HTML-страница с полем ввода имени, полем ввода текста, списком сообщений и кнопками. (CSS и JavaScript — коротко то, что будет видеть пользователь)

**nginx** — тут файл nginx.conf (что отдавать, куда перенаправлять)

Ещё в корне проекта:

- docker-compose.yml (по сути инструкция работы контейнеров и их взаимодействия)
- .env.example (шаблон какой-то)
- .gitignore (это чтобы мой пароль не видели все)
- README.md (этот файл)

## Установка и запуск

### Требования:

- Docker
- Docker Compose

### Запуск:

```bash
docker compose up -d --build
```

После запуска открыть в браузере:

```
http://localhost:8080
```

Если запускаешь на удалённом сервере — использовать IP сервера вместо localhost.

### Остановка:

```bash
docker compose down
```

## Переменные окружения

Все секреты хранятся в файле `.env` (он не попадает в git). В репозитории лежит только `.env.example` — шаблон с именами переменных.

Перед запуском нужно создать `.env` на основе примера:

```bash
cp .env.example .env
```
